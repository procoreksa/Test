# Pro Core Media — الخدمات والباقات (مسودة v1)

> **الحالة:** الخدمات الأربع مؤكدة منك (2026-10-10). **الأسعار استرشادية وتحتاج اعتمادك** قبل نشرها.

## الخدمات المؤكدة
1. إدارة حسابات التواصل الاجتماعي + التصميم
2. إدارة إعلانات Meta (Facebook / Instagram)
3. إنتاج Reels والفيديو والمحتوى بالذكاء الاصطناعي
4. تصميم الهوية البصرية

## قواعد العرض
- لا نَعِد بنتائج رقمية مضمونة؛ نَعِد بخطة واضحة وتقارير شفافة.
- الالتزام الأدنى المقترح: 3 أشهر (خصم مقترح 10% ⚠️ يحتاج موافقتك).
- عرض الإطلاق ⚠️ (يحتاج موافقتك): مراجعة مجانية للحسابات (Free Marketing Audit) لأول 10 منشآت.
